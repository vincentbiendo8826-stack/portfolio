MOD.01 — ABOUT

How I actually work

I'm more interested in how a system is supposed to work than in memorizing syntax. I like figuring out what a process actually needs, spotting where it breaks, and designing something that fixes it — that's why Systems Analysis and Design is where I want to specialize.

When I run into something unfamiliar — a new tool, a broken feature, a requirement nobody explained well — my default is to poke at it until it makes sense. I experiment, look things up, test what I think is true, and adjust when I'm wrong. That's less about being naturally technical and more about being okay with not knowing something yet.

MOD.03 — PROJECTS

Projects

A mix of coursework, one deeper capstone-style build, and one project I started just to see if I could.

Mini Capstone · Systems Analysis & Design

Joroma Barbershop — Online Appointment & Booking System

Built for an actual barbershop client in Davao City. The core of this project was the systems-analysis work before any code: understanding how the shop currently books clients, where that process breaks down, and what a digital booking flow needed to account for — different services per gender, barbers with irregular days off, and a clean line between what customers can touch and what the admin can.

  • Five-step, gender-based booking wizard for customers
  • Drag-selectable calendar for barber day-off management
  • Soft-deletion for admin records instead of hard deletes
  • Strictly separated customer-facing and admin logic
